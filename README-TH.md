# Smart POS V9.64 — วิธีติดตั้งไฟล์แก้ไข

1. สำรอง `index.html` และ `sw.js` ปัจจุบันไว้ก่อน
2. แทนที่ไฟล์ `index.html` และ `sw.js` ใน GitHub repository ด้วยไฟล์ในชุดนี้
3. Commit และรอ GitHub Pages deploy สำเร็จ
4. เปิดเว็บใหม่แล้ว reload หนึ่งครั้ง; Service Worker รุ่น `pos-v16` จะล้าง cache รุ่นเก่าและติดตั้งใหม่
5. เข้าระบบร้านด้วยบัญชี Supabase Auth และ PIN พนักงานตามขั้นตอนเดิม
6. ตรวจป้ายคิวซิงก์: คิวเก่าที่ไม่มี actor จะขึ้น “ต้องตรวจสอบ” ไม่ถูกส่งอัตโนมัติ
7. ทดลองเพิ่มสินค้าทดสอบหนึ่งรายการและอัปโหลดรูปหนึ่งไฟล์ ตรวจ URL และเปิดจากอีกอุปกรณ์

**อย่าลบ LocalStorage/IndexedDB หรือคิวเก่าเอง** ก่อนตรวจรายการ เพราะอาจมีธุรกรรมที่ยังไม่ขึ้น Cloud

ไฟล์ SQL ที่แนบเป็น SQL เดิมที่ผู้ใช้อัปโหลด ไม่ได้แก้ไข schema รอบนี้ เพราะยังไม่มีผลตรวจ policy/สิทธิ์ฉบับเต็มจากโปรเจกต์จริง
